# lumio-workspace

Optional Python 3.14 deployment package for one owner-managed Lumio workspace. It serves an explicitly configured, immutable Published Version through authenticated Streamable HTTP MCP and keeps browser OIDC sessions separate from Pi API access tokens.

This W1 slice provides only `workspace_status`, `read_knowledge`, and `search_knowledge`. It does not upload, initialize, contribute, review, admit, or publish content. Live Entra/private-HTTPS interoperability remains unqualified until an owner-approved synthetic fixture is available.

See [Shared workspace how-to](../../docs/howto-shared-workspace.md) for registration, configuration, owner bootstrap, and client connection.
