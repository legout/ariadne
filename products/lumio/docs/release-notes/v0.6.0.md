## What changed

- **Lossless native verification metadata rendering** — the
  whole-contribution review's profile renderer preserves validated native
  metadata types: mixed boolean/string keys stay distinguishable and a
  native date never collapses into the identical quoted text.
- **Packaged skill guidance** for the optional document-first enrichment
  route: bounded selection, complete candidates, fresh-exact-review
  regeneration, source-backed passages for permissioned reviewers, and
  explicit no-join/no-metric/no-publication authority.

No breaking API changes; optional extras are unchanged.
