# Specification 0038: Lean baseline — test-diet, then deslop

[approved umbrella spec 0037](2026-11-18-0037-simple-ariadne.md). Not approved.

## 1. Goal

Shrink the repository to the code and tests that prove real, still-wanted behavior
before the A/B/C rebuild. The rebuild then carries less weight, and every surviving
test names a reachable failure.

## 2. Scope

All four packages and the shared test roots:

- `products/ariadne/packages/ariadne-data`
- `products/lumio/packages/{lumio-wiki,lumio-lancedb,lumio-workspace}`
- `products/lumio/tests`
- `integration/tests`
- `tests/`

The baseline numbers are in the
[comparison research](../research/2026-11-18-auto-ontology-comparison.md#size-baseline-2026-11-19).

## 3. Non-goals

- No behavior change to surfaces that 0037 keeps. No new features. No changes to the
  Python floor or the Ossie format (sub-spec A).
- No modernization of surfaces that 0037 removes:
  - the separate `ariadne-*` executables,
  - the two-step admission preview and confirm,
  - manual ID/revision/digest plumbing,
  - separate source approval,
  - Staging/Promotion remnants.

  Their code and tests stay untouched in D unless they are already dead today. Sub-spec B
  deletes them.
- No target line counts or percentages. Counts are reported, not optimized.

## 4. Behavior to protect (proof map)

At least one test proving real behavior must survive for each item:

1. **Numerical correctness:** compiled metric SQL returns independently derived golden
   values, including multi-fact alignment.
2. **Grain/fan-out guard:** a fan-out join is refused, and conformed dimensions align
   fact branches.
3. **Read-only execution and source containment:** no write, no unapproved path, DSN or
   bucket outside its scope; credentials only by variable name.
4. **Served-state integrity:** queries serve only an admitted snapshot, and a corrupt,
   missing or mixed release refuses before SQL.
5. **Required Policy and Context closure:** missing required Context refuses before
   calculation, and Policies travel with answers.
6. **Execution attestation** of the reported value.
7. **Lumio:** load, validate, search and traverse; ingest to proposal; publication and
   admission; source-version invalidation; S3 publish manifest integrity;
   original-source authorization.
8. **lumio-workspace:** authentication modes fail closed; capability separation;
   visibility filtering before lookup; one-use review action.
9. **lumio-lancedb:** index binding and fallback disclosure.
10. **Packaging:** wheels install and expose their entry points; Lumio installs without
    Ariadne.

## 5. Rules

- **D1, test-diet** follows the installed `test-diet` skill.
  - Classify every test as keep, merge, replace, delete, flaky or unsure.
  - Every delete, merge or replace names the surviving test and assertion and a fault
    that the survivor catches.
  - Faults are injected only into a scratch copy of the source.
  - The owner approves the concrete per-file tables before anything is applied.
  - Tests that assert source text, private helpers, the existence of names, or only
    mock behavior are deletion candidates by default.
- **D2, deslop** follows the installed `deslop` skill, applied to production code after
  D1.
  - It removes dead code, duplicates, single-use wrappers, narration and milestone
    comments, spec/issue references in code comments, and impossible-state defensive
    code.
  - Public interfaces that 0037 keeps stay intact.
  - Interfaces that 0037 removes are left to B, unless they are already dead.
- A defect found during D is reported as a separate finding. It is not silently fixed.

## 6. Acceptance

1. The owner approves the test-diet table for each package before it is applied. Every
   applied deletion has a recorded survivor and caught fault.
2. Every item of §4 has at least one named surviving test that fails on a deliberate
   fault in a scratch copy.
3. After D1 and D2 the required CI gates (`.github/workflows/ci.yml`) pass on the
   candidate. Ruff is clean on touched files.
4. The report states production and test lines and test counts before and after per
   package, lists files removed or merged, and lists suspicious tests kept with the
   reason.
5. No change to the public CLI/MCP behavior that 0037 keeps. The wheel and install smoke
   checks pass.
