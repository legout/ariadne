# Ariadne examples

For a complete first run, use [Local Lumio + Ariadne](local-lumio-ariadne/README.md).
It supplies authored knowledge and definitions, three synthetic orders, a local
source, explicit human gates, a 150 EUR/two-order result, citations and a Git
update that remains inactive until reviewed confirmation. The software pair is
Core 0.6.0 / Lumio 0.4.0; no model, Docker, S3 or separate Agent is needed.

[`retail-demo/`](retail-demo/README.md) contains additional standalone source
fixtures and a small optional MCP client. It assumes an already admitted project
and is not the combined onboarding recipe.

The [Lumio examples](lumio/) — the scripted onboarding journey, capture
adapters and a real-world Knowledge Base — belong to the independent Lumio
foundation and need no Ariadne installation.
