# Lumio public SDK 0.4.1

Release family: `lumio-wiki==0.4.1` and `lumio-lancedb==0.4.1`.
The adapter requires `lumio-wiki>=0.4.1,<0.5.0`. Both require Python >=3.14.
The private application is outside this public release.

Candidate release preparation for the `lumio-v0.4.1` channel tag in the
current `legout/ariadne` repository; the approved rename to `ariadne-lumio`
is pending a separately authorized cutover and no new URL is implied. These
notes describe the prepared candidate — they do not claim publication.

## Monorepo public paths and shared development workspace

The public foundation now lives in the shared Ariadne–Lumio uv workspace.
Repository-level tests, eval assets, scripts, experiments, examples and docs
moved to `tests/lumio/`, `eval/lumio/`, `scripts/lumio/`,
`experiments/lumio/`, `examples/lumio/` and `docs/lumio/`, while the members
keep their `packages/` paths, distribution names, import roots, console
scripts, extras and packaged resources. Independence is retained:
`lumio-wiki` works without Ariadne, DuckDB, LanceDB, transport SDKs, models
or services unless a selected extra requires them; standalone Core usage is
unchanged; installing both products never activates their integration. The
optional LanceDB adapter follows the existing native lockstep policy and now
requires `lumio-wiki>=0.4.1,<0.5.0`.

## Corrections in this patch release

- Repaired relocated local/Git onboarding and documentation paths — the
  quickstart and S3 publication guide wiring, the experiment runbooks and
  the packaged-skill surface references — so the documented runnable
  examples resolve in the monorepo layout.
- Corrected development CI: the relocated repository tests resolve as
  `tests.lumio` under namespace-aware collection with relative sibling
  imports, and the Core member lint selects its existing dev extra for the
  lint tool.
- No runtime feature, API, dependency or compatibility change beyond the
  adapter's approved family minimum. Navigation over admitted local
  Published Versions remains local-only; the existing optional extras are
  unchanged.

## Compatibility and pairing

`lumio-wiki==0.4.1` remains compatible with the existing public Core 0.6.0
pairing documented in
[the SDK integration reference](../ariadne-context.md); a future Core 0.6.1
consumer pairing is prepared separately on the Ariadne side. This release
makes no numerical attestation, full-compliance or production-readiness
claim.
